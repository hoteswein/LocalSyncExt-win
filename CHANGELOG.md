# Журнал изменений

## v0.3.0 — 2026-10-12
- Корзина вне синхронизируемой папки: `Trash=work` (папка WorkDir, по умолчанию `work` рядом с exe) или `Trash=D:\путь`; в `[Settings]` — для всех правил, в правиле — для одного. Если корзина на другом диске, файл копируется и удаляется (Rename между дисками невозможен).
- Временные файлы: малые файлы (до `DirectBelow` КБ, по умолчанию 1024) пишутся сразу в целевое место; большие — через временный файл `LocalSyncExt-ДАТА-ВРЕМЯ-имя` рядом с целевым (`Temp=prefix`) или в `WorkDir\tmp` (`Temp=work`, только на том же диске) с переименованием после полного копирования.
- Осиротевшие временные файлы (старше суток) удаляются автоматически; обычные файлы с похожими именами не затрагиваются.
- Проверка: рабочая папка не должна лежать внутри синхронизируемых путей.

## v0.2.0 — 2026-10-12
- Мгновенная синхронизация: слежение за папками средствами Windows (ReadDirectoryChangesW), один дескриптор на весь путь, без обхода дерева. Параметры правила: `watch=1|0`, `debounce=1500` (мс накопления событий).
- Инкрементальная обработка: по событию проверяются только изменившиеся файлы (кэш в памяти); полное сканирование остаётся страховкой (`scan`, по умолчанию 900 с при слежении и 60 с без него).
- Настройки на лету: файл ini перечитывается при изменении; неизменённые правила работают без перерыва. Ошибка в новом файле или в правиле не останавливает работающую версию.
- Маркер отключается: `marker=0` для всего правила или `nomarker=2,3` для отдельных путей (номера строк путей). Защита идёт по пути, серийному номеру тома (Windows) и базе в папке state; в такие папки служебные файлы не пишутся.
- Защита от подмены диска: сравнение серийного номера тома.
- Состояние хранится в памяти и сбрасывается на диск не чаще раза в 5 с (меньше записей на диск).
- Релизы публикуются в GitHub Releases с номером версии; exe знает свою версию (`-version`).

## v0.1.0 — 2026-10-11 (без публикации)
- Консольное ядро: двусторонний и односторонний режимы, папки, маски и отдельные файлы, конфликты в стиле Syncthing, корзина (TrashDays), защита от массового удаления, проверка пересечения правил.

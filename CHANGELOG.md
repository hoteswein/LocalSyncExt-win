# Журнал изменений

## v0.5.0 — 2026-10-18
- Веб-интерфейс (без внешних библиотек, встроен в exe): список правил с аннотациями мелким шрифтом, редактор правила, страница «Статус и журнал», страница настроек. Версия программы указана внизу каждой страницы.
- Два порта: `WebPortOpen` — без авторизации (для ZeroTier, локальной сети; по умолчанию слушает только 127.0.0.1) и `WebPortAuth` — вход по логину и паролю, затем cookie на 30 дней. Адреса и порты настраиваются (`WebOpenBind`, `WebAuthBind`). Выключается целиком `WebUI=0`; порты применяются без перезапуска.
- Защита: пароль хранится как PBKDF2-хэш в state\web.json, подписанные cookie (HttpOnly, SameSite=Strict), ограничение подбора пароля, проверка Host/Origin (DNS rebinding, CSRF), обязательный заголовок для изменяющих запросов. Логин и пароль: страница настроек или `-web-user`/`-web-pass`.
- Редактор правила: название, аннотация (`description`), режим, главный путь, конфликты, корзина, слежение, сканирование, дополнительные параметры; пути вводятся вручную или выбираются кнопкой «Обзор…» (файлы, папки, несколько сразу, папка + маска); у каждого пути отметка «без маркера».
- Сохранение через веб проверяется так же, как при загрузке; при ошибках файл не меняется. Прежняя версия сохраняется в `.ini.bak`; если ini изменили вручную, веб предложит обновить страницу. Комментарии внутри правил при сохранении не сохраняются (заголовок файла — сохраняется), для пояснений используйте аннотацию.
- Статус и журнал: состояние, время последнего прохода и последнего изменения, счётчики, последняя ошибка; журнал событий с фильтрами и хвост файла журнала.
- Трей: действие `ui` и пункт меню «Открыть веб-интерфейс»; двойной щелчок по умолчанию открывает веб-интерфейс.

## v0.4.0 — 2026-10-13
- Значок в трее (чистый Win32, без сторонних библиотек). Две сборки: `LocalSyncExt.exe` — без консольного окна, сразу в трее; `LocalSyncExt-cli.exe` — консольная (для `-check`, `-once`, `-dry-run`, отладки; значок включается флагом `-tray`).
- Анимация: при синхронизации вращаются стрелки; отдельные значки для паузы и ошибки. Размер значка подбирается под масштаб экрана.
- Правая кнопка — меню: статус и подменю каждого правила (синхронизировать сейчас, пауза/продолжить), «Синхронизировать всё», «Приостановить всё», журнал, ini, перечитать конфиг, уведомления, автозапуск, выход.
- Левый щелчок и двойной щелчок — разные действия, настраиваются: `TrayClick` (по умолчанию `status`) и `TrayDoubleClick` (по умолчанию `syncnow`); значения `status|syncnow|pause|log|config|notify|none`.
- Автозапуск с Windows сразу в трей (пункт меню, запись в HKCU\...\Run, без прав администратора).
- Уведомления Windows: общий выключатель `Notifications` и `notify` в каждом правиле; частые уведомления объединяются в сводку (не чаще раза в 5 с).
- Пауза и «синхронизировать сейчас» в движке (для трея и будущей веб-страницы); на паузе события не копятся, после снятия — полное сканирование.
- Один экземпляр на конфиг; иконка и манифест (DPI, длинные пути) встроены в exe.

## v0.3.0 — 2026-10-12
- Корзина вне синхронизируемой папки: `Trash=work` (папка WorkDir, по умолчанию `work` рядом с exe) или `Trash=D:\путь`; в `[Settings]` — для всех правил, в правиле — для одного. Если корзина на другом диске, файл копируется и удаляется (Rename между дисками невозможен).
- Временные файлы: малые файлы (до `DirectBelow` КБ, по умолчанию 1024) пишутся сразу в целевое место; большие — через временный файл `LocalSyncExt-ДАТА-ВРЕМЯ-имя` рядом с целевым (`Temp=prefix`) или в `WorkDir\tmp` (`Temp=work`, только на том же диске) с переименованием после полного копирования.
- Осиротевшие временные файлы (старше суток) удаляются автоматически; обычные файлы с похожими именами не затрагиваются.
- Проверка: рабочая папка не должна лежать внутри синхронизируемых путей.

## v0.2.0 — 2026-10-12
- Мгновенная синхронизация: слежение за папками средствами Windows (ReadDirectoryChangesW), один дескриптор на весь путь, без обхода дерева. Параметры правила: `watch=1|0`, `debounce=1500` (мс накопления событий).
- Инкрементальная обработка: по событию проверяются только изменившиеся файлы (кэш в памяти); полное сканирование остаётся страховкой (`scan`, по умолчанию 900 с при слежении и 60 с без него).
- Настройки на лету: файл ini перечитывается при изменении; неизменённые правила работают без перерыва. Ошибка в новом файле или в правиле не останавливает работающую версию.
- Маркер отключается: `marker=0` для всего правила или `nomarker=2,3` для отдельных путей (номера строк путей). Защита идёт по пути, серийному номеру тома (Windows) и базе в папке state; в такие папки служебные файлы не пишутся.
- Защита от подмены диска: сравнение серийного номера тома.
- Состояние хранится в памяти и сбрасывается на диск не чаще раза в 5 с (меньше записей на диск).
- Релизы публикуются в GitHub Releases с номером версии; exe знает свою версию (`-version`).

## v0.1.0 — 2026-10-11 (без публикации)
- Консольное ядро: двусторонний и односторонний режимы, папки, маски и отдельные файлы, конфликты в стиле Syncthing, корзина (TrashDays), защита от массового удаления, проверка пересечения правил.
